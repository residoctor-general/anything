# 個人用の診療サポート道具

医師本人が個人で使うための道具。事業化はしない（医療機器として承認を取る段階は、個人会社には現実的でないと判断したため）。

## 作るもの

### 1. 個人情報を伏せるページ
- カルテの文章を貼ると、ブラウザの中だけで個人情報を伏せる。外には送らない。
- 1段目：決まった規則（正規表現と辞書）で除去する。対象は患者ID、電話番号、日付（「○日前」に変換）、年齢（「70代」に丸める）、住所、施設名、医師名、氏名（「様」「さん」などの目印と姓の辞書）。
- 2段目：ブラウザの中で動くAIでさらにチェックする（使える環境の場合のみ）。
- 送信前の確認画面で、伏せた箇所と怪しい箇所を色で表示する。
- 病院のPCではClaudeにログインしない。

### 2. 相談役（全分野）
- まず residoctor.com を参照し、記事がなければ他の情報源を参照する。
- 回答の型：評価 → 鑑別 → 検査計画 → 処方調整 → 根拠（residoctor／外部情報／AI自身の知識を区別する）→ 注意点

### 3. residoctorの記事の不備を知らせる機能
- 相談中に記事が古い、または間違っていると分かったら、general@residoctor.com 宛てに知らせる。
- メールに入れる内容：記事のURL、問題の箇所、正しい情報とその出典、重要度（誤りか、古いだけか）
