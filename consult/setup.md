# 相談役の準備手順

## 1. プロジェクトを作る（PCのブラウザで1回だけ）
1. claude.ai を開き、左メニューの「プロジェクト」→「新しいプロジェクト」
2. 名前：「診療相談」（何でもよい）
3. プロジェクトの「指示（カスタム指示）」に、`consult/project-instructions.md` の「ここから」〜「ここまで」を貼って保存

## 2. 使う道具をオンにする
- ウェブ検索：チャット入力欄の「検索とツール」のメニューで「ウェブ検索」をオン
- Gmail：設定 →「コネクタ」で Gmail がつながっているか確認（記事の不備の下書き用）
- PubMed：同じく「コネクタ」で PubMed がつながっていれば使える（なくても動く）

## 3. 確認しておく設定
- 設定 →「プライバシー」で、会話をモデルの改善（学習）に使う設定がオフになっているか

## 4. 使い方（iPhone）
1. 病院のPCで伏せるページを使い、QRコードでiPhoneへ
2. 受け取りページで「コピー」
3. Claudeアプリでプロジェクト「診療相談」を開き、新しいチャットに貼って、相談したいことを書く
4. 使い終わったら受け取りページで「削除」。古い会話はときどき削除する

## 最初の試し方
架空の文章で、次のような相談をしてみる。
- 「70代男性、PPI長期内服中。続けるべきか、減量するか」
- 「急性膵炎の初期輸液量の目安」（residoctorの記事が参照されるか確認）
