# 相談役の準備手順

## 方式
claude.ai のスキル「shinryo-soudan」として登録している（2026-11-18 登録済み）。
チャット用のプロジェクト（「指示」欄のあるもの）は、このアカウントの画面では作れなかったため、スキル方式にした。

- 伏せたカルテ文（【氏名】などを含む文章）を貼ったとき、または「相談：」で始めたときに自動で使われる。
- 普段のチャットには影響しない。
- 使う道具：ウェブ検索、Gmail（記事の不備の下書き用）、PubMed（いずれも接続済み）。
- 「AIモデルの改善に協力する」はオフ（確認済み）。

## 指示を直すとき
1. `consult/project-instructions.md` を直す
2. `consult/skill/shinryo-soudan/SKILL.md` と `consult/shinryo-soudan.zip` を作り直す
3. claude.ai の「カスタマイズ」→「スキル」で、古い shinryo-soudan を新しい zip に入れ替える

## 使い方（iPhone）
1. 病院のPCで伏せるページを使い、QRコードでiPhoneへ
2. 受け取りページで「コピー」
3. Claudeアプリで新しいチャットを開き、貼って相談したいことを書く（伏せた文章がないときは「相談：」で始める）
4. 使い終わったら受け取りページで「削除」。古い会話はときどき削除する
